# Fabric Doctor — Website Design Preview

Design preview of the Fabric Doctor website: sofa, mattress, chair and carpet deep cleaning in Sri Lanka.

This build shows the landing page — its full look, layout and animations, with sample reviews.
The other pages are still in progress and show a "Still working on it" screen.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
