# Fabric Doctor — Website Design Preview

Design preview of the Fabric Doctor website: sofa, mattress, chair and carpet deep cleaning in Sri Lanka.

This build shows the full look, layout and animations of the public site with sample content.
Reviews shown are samples, and the contact and review forms are not connected yet — nothing is sent or saved.

## Pages

- Home, with the intro animation (plays once per visit)
- Service pages: sofa, mattress, chair and carpet cleaning
- Reviews & Moments
- Stain & Care Guide
- About
- Contact

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
